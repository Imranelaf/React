React Virtuoso Example

The main purpose of this project is to render a large amount of data (1000 in our case) efficiently in React using the react-virtuoso library.

The example initializes a list of users and displays them using the Virtuoso component.

Key Features

Virtualized List Rendering: Efficiently renders a large list of items with react-virtuoso.

Dynamic Data Handling: Demonstrates how to pass dynamic data to the list.
